## Milestone goal

A running DSH/Cordis process exposes the same live runtime diagnostics to:

- developers through the existing Cordis DevTools UI;
- in-process DSH agents through Cordis Inspect;
- external coding agents through an embedded loopback MCP endpoint.

All machine-facing adapters share one Runtime Diagnostics Query layer.

## Wave E — Agent debugging proof

Status: complete across #38, #36, and #37

Fixture scenario:

- create two live Fibers with the same runtime name that both own a listener for one event while the source-level shape appears singular;
- query the Agent-facing interfaces without opening the DevTools panel.

Expected evidence chain:

```text
inspectEvent
  → two current listeners
  → two distinct live owner uids
  → one shared owner name
inspectFiber(name)
  → both authoritative live Fibers
inspectFiber(uid A / uid B)
  → each uid resolves independently
  → each Fiber owns the duplicate event
searchDispatches
  → bounded recent occurrence evidence
  → observed record reports registeredListeners = 2
```

The dispatch record is **not** used to infer listener ownership from dispatch context. Ownership comes from the current listener/Fiber registry; dispatch history contributes only bounded recent occurrence evidence.

Deliverables:

- [x] deterministic transport-neutral semantic fixture (#38);
- [x] real DSH duplicate-Fiber runtime fixture;
- [x] DSH Cordis Inspect query proof (#36);
- [x] external official MCP Client proof (#37);
- [x] one final real DSH smoke proving Cordis Inspect, external MCP, and Human UI against the same runtime;
- [x] documentation showing what runtime evidence adds beyond source inference (#32).

## Parallel execution result

The implementation followed the intended fan-out after the shared Query contract:

```text
                    Runtime Diagnostics Query (#33)
                              │
                ┌─────────────┴─────────────┐
                ▼                           ▼
      Cordis Inspect (#34)          MCP Adapter (#35)
                │                           │
         real DSH #36               real DSH #37
                └─────────────┬─────────────┘
                              ▼
               duplicate-Fiber evidence proof
                     shared semantics #38
```

The adapters remain thin: filtering/evidence semantics live in Runtime Diagnostics Query. The final real DSH smoke retains the #36 Cordis Inspect proof and layers the #37 external MCP proof into the same process before continuing the human UI/profiler assertions.

## Intentionally deferred beyond the first v0.4 slice

- profiler mutation tools;
- generic `diagnose()` / confidence heuristics;
- external remote/LAN access;
- stdio proxy/bridge;
- automatic client configuration generation;
- multi-DSH runtime discovery;
- persistent runtime checkpoints/diffs;
- full lossless telemetry or payload capture;
- profiling of non-waterfall modes.
